# DIY Laser Cutter / Engraver

Design and build log for a homemade laser cutter and engraver.

## Repo layout

- `docs/decisions/` — Architecture Decision Records (ADRs). Each significant design choice (frame material, laser type/power, motion system, controller board, software stack, safety systems, etc.) gets its own numbered record: context, decision, consequences.
- `docs/` — general design notes, reference material, specs.

## Status

Just getting started. See `docs/decisions/` for the running log of decisions as we make them.
